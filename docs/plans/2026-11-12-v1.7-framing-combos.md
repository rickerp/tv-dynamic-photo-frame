# TV Photos 1.7 Implementation Plan

> **For agentic workers:** executed inline in the session that wrote it (the user said "build it"). Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Framing editor, hide switch, combinations (pair, row3, big3, grid4) and remote ◀ ▶ for TV Photos,
as specified in `docs/specs/2026-11-12-v1.7-framing-combos-design.md`.

**Architecture:** One pure-Java `Framing` class holds the placement maths and layout boxes (unit tested, and
mirrored in the page's JS). `Library` keeps per-photo framing/hidden flags and combinations in
`files/library.json`. The screensaver draws every slide (a photo or a combination) with one `SlideView`.

**Tech Stack:** Java 17, Android SDK 34 (minSdk 26), no AndroidX; org.json on the device; JUnit 4 for
`Framing`; plain HTML/JS for the page.

## Global Constraints

- minSdk 26, targetSdk 34, no new runtime dependencies; signed with `~/.android/debug.keystore`.
- versionCode 8, versionName 1.7. Existing photos, the PIN, weather and settings must survive the update.
- Every new API route sits behind the existing PIN cookie and validates names with `Store.validName`.
- `x, y` clamp to 0..1, `z` to 0.05..4. Layout names: `pair`, `row3`, `big3`, `grid4`.
- The page stays one file (`app/src/main/assets/index.html`), usable at 375 px wide.

### Task 1: Framing maths

**Interfaces — Produces:**
- `static float[] Framing.place(float w, float h, float pw, float ph, float x, float y, float z)` →
  `{left, top, drawnW, drawnH}` in box pixels.
- `static float Framing.fitZoom(float w, float h, float pw, float ph)` → `min/max` ratio.
- `static float[][] Framing.boxes(String layout)` → fractional `{x, y, w, h}` per box, or null.
- `static int Framing.cells(String layout)` → 2, 3, 3, 4, or 0 for unknown.

- [ ] Write `FramingTest`: cover centred (1000x500 photo in 100x100 box → drawn 200x100, left -50);
      x=0 clamps left to 0; x=1 clamps left to -100; fit zoom (z=0.5) → 100x50 centred top 25; z above 4
      clamps to 4; `boxes("big3")` second box = {2/3, 0, 1/3, 1/2}; `cells("nope")` = 0.
- [ ] Run `./gradlew testReleaseUnitTest` → fails (no class).
- [ ] Implement `Framing` as in the spec formula.
- [ ] Run tests → pass.

### Task 2: Library

**Interfaces — Produces:**
- `Library(File dir)`; `synchronized` methods; `load()` reads, `save()` writes atomically.
- `float[] frame(String name)` → `{x,y,z}` or null; `void setFrame(String name, float x, y, z)`;
  `void clearFrame(String name)`.
- `boolean hidden(String name)`; `void setHidden(Collection<String> names, boolean off)`.
- `List<Combo> combos()`; `String saveCombo(Combo c)` (new id when `c.id == null`);
  `boolean deleteCombo(String id)`; `void setCombosHidden(Collection<String> ids, boolean off)`;
  `int forgetPhotos(Collection<String> names)` (drops photo meta and the combos that use them).
- `static final class Combo { String id; String layout; boolean off; List<Cell> cells; }`,
  `static final class Cell { String photo; float x, y, z; }`.
- `String toJson(List<String> existingNames)` → `"meta":{...},"combos":[...]` fragment for the list route.

- [ ] Implement with org.json; drop combos whose photos are missing or whose cell count mismatches the layout.
- [ ] Verified through the API in Task 3 (org.json is stubbed in JVM tests).

### Task 3: Server routes

- [ ] `list()` appends `Library.toJson(names)`.
- [ ] `/api/frame` (`name`, `x`, `y`, `z` | `reset=1`), `/api/show` (`on`, `names`, `combos`, comma lists),
      `/api/combo` (JSON body `{id?, layout, off?, cells:[{p,x,y,z}]}`), `/api/combo/delete` (`id`).
- [ ] `/api/delete` calls `library.forgetPhotos()` and returns `combosRemoved`.
- [ ] Check with curl against the TV after install (Task 6): 400s for bad names/layouts, 401 without cookie.

### Task 4: Screensaver

**Interfaces — Consumes:** `Framing.place/boxes`, `Library`. **Produces:** `SlideView.show(Slide, Bitmap[])`.

- [ ] `SlideView extends View`: holds boxes in px, bitmaps and framings; `onDraw` clips each box and draws
      its bitmap with `Framing.place`. Gap 8 px at 1920 wide.
- [ ] `PhotoDream`: `Slide` = single photo (box = whole screen, framing from Library or the fill default)
      or combo. Queue of slide keys refilled + shuffled each round; history list (max 50) with a cursor.
- [ ] `setInteractive(true)`; `dispatchKeyEvent`: DPAD_LEFT/RIGHT down (repeat 0) → `step(-1/+1)`; any other
      key down → `wakeUp()`; consume all.
- [ ] Decode each box's bitmap with an inSampleSize that keeps it at least box size × zoom.
