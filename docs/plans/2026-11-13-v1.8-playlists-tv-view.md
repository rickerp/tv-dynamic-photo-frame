# TV Photos 1.8 Implementation Plan

> **For agentic workers:** executed inline in the session that wrote it (the user said "Yes, build it").
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Playlists that choose what the screensaver plays, and the phone page inside the TV app, as
specified in `docs/specs/2026-11-13-v1.8-playlists-tv-view-design.md`.

**Architecture:** Playlists live in `Library` (library.json) next to framings and combinations. A pure-Java
`Playing` helper filters a round of slide keys by the switched-on playlists (unit tested). The TV view is a
WebView activity on the existing page with `?tv=1`, which adds a TV layout and arrow-key focus moving.

**Tech Stack:** Java 17, Android SDK 34 (minSdk 26), no AndroidX, android.webkit.WebView; plain HTML/JS.

## Global Constraints

- minSdk 26, targetSdk 34; no new dependencies; debug-key signing. versionCode 10, versionName 1.8.
- Playlist ids `p<13 digits>_<6 hex>`; names trimmed, 1-40 chars, no control characters.
- With no playlist on, or nothing visible in the ones on: play every visible item (1.7 behaviour).
- The WebView loads only `http://127.0.0.1:8080/`; any other URL is refused.
- Existing photos, combinations, the PIN, weather and settings survive the update.
